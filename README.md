Brilho Natural
=======
# Brilho Natural

Aplicacao web adaptada para rodar com `npm run dev`, sem Expo e sem Snack.

## Requisitos

- Node.js 20 ou superior
- npm

## Instalar dependencias

```bash
npm install
```

## Rodar em desenvolvimento

```bash
npm run dev
```

O Vite vai subir o projeto localmente, normalmente em `http://localhost:5173`.

## Build de producao

```bash
npm run build
```
